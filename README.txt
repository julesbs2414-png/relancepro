RelancePro v0.8 — prototype interactif

Ouvrez index.html dans un navigateur moderne.

Nouveautés v0.8 : relance multicanale (e-mail/SMS/WhatsApp), choix du ton, simulateur d'envoi, acomptes, pénalités de retard, étiquettes, statut litige + mise en demeure, journal d'activité, statistiques/trésorerie/ROI, export CSV et PDF, vitrine de réalisations (+ export .html), parrainage, FAQ, bouton d'avis (changez FEEDBACK_TO dans index.html), mode hors-ligne (sw.js, nécessite un serveur http/https).
Avant :  modèles de relance personnalisables, envoi via votre messagerie (mailto), historique des relances, export calendrier (.ics), notifications navigateur, import CSV (client;objet;montant;email;date), pipeline, tarifs, page confidentialité avec export et suppression des données.

Limites : données stockées dans le navigateur uniquement, pas de compte réel, pas d'envoi automatique, pas d'OCR, pas de paiement. N'utilisez pas de données sensibles tant qu'un serveur sécurisé n'est pas en place.
